## 方法论

每张卡片按六步模板：
1. **事件表象** — 表面发生了什么
2. **直接影响** — 勾动了哪些变量
3. **连锁传导** — 顺图走三跳 + 交易拥挤度 + 最先被冻住的是谁
4. **深层目的** — 操盘手四象限倒推
5. **时间窗口** — 验证/证伪节点
6. **普通人影响** — 你的钱包 + 你的资产

附加规范：
- **F1** 市场当前定价（price in 了什么，证伪条件）
- **F2** 每日唯一要盯的证伪变量
- **F3** step-6 分两层：钱包 + 资产
- **F4** 交易拥挤度观察
- **F5** 正反面都写
- **G1** 街角信号（方便面/折扣零售/劳务工价/黄金回收）
- **G2** 怀疑表针被掰回去
- **G3** 最先被冻住的是哪类人
